# Archive — records of work that is no longer live

Nothing here describes the current product. Each subdirectory is a dated record kept
for its reasoning, not for its rules; the live documents are linked from
[`docs/README.md`](../../README.md).

| Area | What it is | Why it is kept |
|---|---|---|
| [`v1/features/`](v1/features/INDEX.md) | The v1 feature registry: one file per feature, with user stories, acceptance criteria and the v1 code paths | The port still reads it for behaviour that the live inventory names only; git history holds the code it describes |

A record moves here when a live document replaces it, in the same change that
introduces the replacement. The replacement links back; the archived record does not
get updated except to correct a pointer that the move broke.
