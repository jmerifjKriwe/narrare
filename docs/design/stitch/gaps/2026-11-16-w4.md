## Why placeholders exist

The owner's condition is fidelity to the drafts without lies: a feature the
backend cannot serve keeps the draft's geometry with an honest neutral — a
disabled control with the drafted note, a „—", never an invented number,
never a fabricated state. The drafts' mock figures (412/500 W., 82 %,
3.384 Wörter, „Akt I · Höhepunkt") are draft data, never shipping data: the
port renders the real value or the documented neutral. Where the round
removed an element the variants drew, the omission is argued here instead of
silently dropped — and nothing is invented in its place (Stitch is sole
authority; the round owns final geometry, design §6).

Rows come in four kinds:

- **Feature gaps** — a drafted control whose action does not exist yet. It
  renders disabled with the draft's own note („kommt später", „bald").
- **Draft gaps** — the draft overlooked something or claims a fact the
  backend does not carry (a storage technology that does not exist, a state
  the sheet never draws). The interim is the honest rendering; the trigger
  is a corrected draft through a Stitch round or the named backend fact,
  never a local invention.
- **Reason rows** — deliberate omissions with no trigger: the element would
  claim a feature that does not exist (pagination, versioning). They return
  only if the named re-open condition becomes true.
- **Owner-decision rows** — the audit found a logical error or an unintended
  claim; the owner alone decides (rework via Stitch, placeholder, or cut —
  design D13). They hang under the index as their own children.

### Reading the rows

- **Rows 1–6** are the knowledge/chat family: the dock's drafted geometry
  ships neutral or disabled (D4), and the two prose elements the round
  removed stay out until a corrected draft draws them. The findings API
  exists — row 1's trigger is content, not backend.
- **Rows 7, 9, 18** are reason rows: versioning and pagination do not exist;
  the elements return only with their named features. Row 7 records the
  round's omission of the badge §8's interim had named — the anti-goal
  forbids inventing a badge the authority does not draw.
- **Rows 10–12, 16–17** are the disabled-control family: each ships with the
  draft's own „kommt später" note, and each trigger is a later wave's
  drafted surface (editing, production, audio, layout, palette).
- **Rows 8, 13, 14** are draft gaps the port answers honestly: a status
  field, style presets and tension data do not exist; the neutral dot, the
  „—" and the placeholder curve claim nothing.
- **Row 15** is the round's own removal, recorded so nobody re-imports the
  variants' spines as authority.

## How a row becomes real

1. Land the trigger the row names (a surface, a field, a corrected draft, an
   owner decision).
2. Replace the interim at the element; a disabled control becomes the real
   door, an omitted element returns only if its re-open condition is met.
3. Update the row here (or remove it if nothing is left) in the same commit.
4. Close the row's child from that commit: `Closes #<n>`. The index (#865)
   closes with its last child.

No placeholder is removed by deleting its slot — the slot is the draft's,
and it stays. Only the neutral content is replaced.
