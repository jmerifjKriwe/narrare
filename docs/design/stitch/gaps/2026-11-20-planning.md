## Why placeholders exist

The owner's condition, carried from W3–W5: fidelity to the drafts without
lies. A feature the backend cannot serve keeps the draft's geometry with an
honest neutral — a disabled control with the drafted note, a „—", never an
invented number, never a fabricated state. Planning adds two rules of its
own. The siblings' rule (real fields only): a field the model does not carry
is not ported — the draft's mock figures („Vor 9 J.", „ca. 25 % · 16.250
W.", „Letzter Abgleich vor 4 Min.") are draft data, never shipping data, and
an invented derivation (a transition's summary sentence) never stands in for
content no scene carries. The vocabulary gate: the branch/what-if vocabulary
is held at grep-zero, so even the strip draft's own disclaimer sentence —
it negates „Verzweigungen" but contains the word — ships nowhere.

## Known-pattern notes (no row owed — the pattern is the record)

- **The fan-out read's one key shape** (Task 3's hook): the per-chapter
  aggregate reads cache under `["planning", "scenes", chapterId]` and the
  aggregate save invalidates exactly that family; the timeline counters and
  the strip ride the same `useNovelScenes` instead of inventing two
  mechanisms (the design's own decision). The rule the shape sets: the next
  novel-wide planning read joins this family or names why it cannot —
  mirroring the W5 relations pair's rule.
- **The rail door's one-target shape** (Task 3, the Wissen ruling's
  planning instance): a capability with several surfaces keeps ONE rail
  door that opens the first surface and wears the active face on all of
  them. A fourth planning surface joins the pattern silently; row 21 holds
  the only open question about it.
- **Stage selects are addressed by name** (Task 6's scoping lesson): every
  stage `<select>`'s accessible name lists all the stages, so text-based
  filters match every occupied column — tests and E2E legs select by
  `aria-label`, never by option text. Harmless today; a select whose name
  stops naming the stages breaks its own tests, loudly.

## How a row becomes real

1. Land the trigger the row names (a surface, a field, a corrected draft, an
   owner decision, or user feedback).
2. Replace the interim at the element; a disabled control becomes the real
   door, an omitted element returns only if its re-open condition is met.
3. Update the row here (or remove it if nothing is left) in the same commit.
4. Close the row's child from that commit: `Closes #<n>`. The index (#927)
   closes with its last child.

No placeholder is removed by deleting its slot — the slot is the draft's,
and it stays. Only the neutral content is replaced.
