# CR-07 v3 Phase A Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Complete CR-07 Follow-up v3 Phase A (CR-AUFG-07-14 and CR-AUFG-07-15) without production shortcuts: remove visible KB/Worldbuilding/Consistency i18n fallbacks, add a localized low-noise GhostText fetch-error affordance, and enforce both with Platform gates.

**Architecture:** Root cause: CR-07 currently governs AI-operation lifecycle evidence, but it does not block visible translation fallback drift or GhostText non-abort fetch failures that disappear without user understanding. The solution is cleanup plus a durable checker, not another one-off edit.

**Tech Stack:** Next.js/React/TypeScript, TipTap v3, next-intl, Vitest, Python checker modules under `scripts/checks/_ai_interaction_checks/`, pytest via `uv run pytest`, `just check-ai-ux`, `just check-frontend-size`.

---

## Scope, Root Cause, Alternatives

**In scope:** CR-AUFG-07-14, CR-AUFG-07-15, DE/EN/FR `studio.json` parity, checker tests, AUFG evidence after gates pass.

**Out of scope:** Phase B/C, new dependencies, Backend/Core API changes, production implementation by Architecture.

**Warum 1:** Tests mock `t()` as a key-returning function, so `t(...) || "English"` never fails and silently preserves drift.

**Warum 2:** Existing `just check-ai-ux` checks operation lifecycle/inventory, but not visible fallback expressions.

**Chosen design:** Remove visible fallbacks, rely on registered i18n keys and structured errors, expose GhostText failure through localized extension options, and add Check 12 for reintroduction prevention.

**Rejected alternatives:**
- Cleanup only: rejected because regression is not prevented.
- Ban all string literals in KB TSX: rejected because it flags non-visible data/test IDs/class names.
- Modal GhostText errors: rejected because it interrupts typing and violates the low-noise requirement.
