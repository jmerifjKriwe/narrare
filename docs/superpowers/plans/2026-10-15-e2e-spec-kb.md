- Consumes: `PromptComposer(PromptRegistry())` (real composer, established unit-test pattern), `StaticModelResolution` (already imported in the test file).

**Root cause (2× why):**
- Why does the KB-004 check silently return zero entry-internal issues? `_analyze_entry` passes `mode=LLMIntent.KB_CONSISTENCY.value` — the INTENT's enum value (`"kb_consistency"`) — where a route-table MODE string belongs. `resolve_prompt_route` treats any non-empty `context.mode` as an explicit context-mode route and rejects it against `allowed_context_modes={"consistency", "merge"}` → `PromptRouteNotConfiguredError` per entity, swallowed by `analyze_entries`' broad `except Exception: continue` (RULE-11-logged but behaviorally silent: 200 + `entity_count > 0` + 0 issues).
- Why was it never caught? Every existing test injects `FakeComposer` (unit) or overrides the service via `dependency_overrides` (integration) — the real composition path never ran in a test. The copy-paste smell (enum value where the sibling `merge_service.py:176` correctly passes the plain string `"merge"`) survived because nothing exercised the real composer.

**Alternatives considered:**
1. `mode="consistency"` explicit string (chosen) — mirrors `merge_service.py`'s explicit `mode="merge"`; the governed template already exists; one line.
2. Omit `mode` (default resolves to `"consistency"` via `INTENT_TO_MODE` + `default_mode`) — equally correct but loses the explicitness that documents WHICH route the analyzer uses; the sibling convention is explicit. Rejected on convention.
3. Add `"kb_consistency"` to `allowed_context_modes` and ship an alias template — governs the WRONG string (an intent name, not a mode) and creates an orphan-template hazard; the route table is correct as shipped. Rejected.

def capture_json_response(page: Page, needle: str):
    """Attach a listener for the next JSON response matching *needle*.

    Returns a zero-arg getter that blocks (bounded, sync-poll form) until
    the matching response landed and returns its parsed JSON. Attach
    BEFORE the action that triggers the request.
    """
    import time

    slot: list[dict] = []

    def _on_response(response) -> None:
        if needle in response.url and not slot:
            try:
                slot.append(response.json())
            except Exception:  # noqa: BLE001 — non-JSON responses are simply ignored
                pass

        while not slot and time.monotonic() < deadline:
            page.wait_for_timeout(250)
        assert slot, f"No JSON response matching {needle!r} within 60s"
        return slot[0]
