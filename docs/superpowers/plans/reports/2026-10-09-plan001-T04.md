- **`apps/api/narrare/planning/scene_service.py`** — `ScenePlanService` ctor
  `(scene_repo, chapter_repo, novel_repo)` (DI, protocols only):
  - `get_aggregate(chapter_id, user_id, *, novel_id)` — uid-scoped novel
    guard (`get_by_id(novel_id, user_id)` → `NotFoundError`, foreign ≡
    unknown), chapter-must-belong-to-novel guard, scenes ordered by position,
    **no auto-create**, `version_updated_at = max(updated_at)` or now.
  - `save_aggregate(...)` — guards first, then spec §5.3 diff-sync:
    duplicate payload id → `ValidationError("duplicate scene id")` **before
    any repo call** (no partial mutation); payload mapped to transient
    `ScenePlan` rows (`_from_schema` — id is the diff key, position/
    timestamps DB-owned); `bulk_replace` wrapped: `IntegrityError` (foreign
    scene id → insert → PK collision) → logged + `ValidationError("unknown
    scene id")`; returns a fresh `get_aggregate` re-read.
  - `_to_schema` / `_from_schema` + `_ref_to_raw` / `_to_ref_schema` /
    `_to_aggregate` module-private (RULE-06); hybrid refs round-trip
    `{"id": "<uuid>"|None, "name": ...}` without rewriting user content
    (RULE-22 §7); `cast` for the stored-status Literal (house pattern — no
    new `type: ignore`, RULE-23).
