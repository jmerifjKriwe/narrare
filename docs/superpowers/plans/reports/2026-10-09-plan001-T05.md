- **`apps/api/narrare/planning/router_scenes.py`** (new, 43 lines ≤ 150) —
  `APIRouter(prefix="/scenes", tags=["planning"])` with exactly two thin
  routes (RULE-06, immediate delegation, no logic):
  - `GET /{novel_id}/{chapter_id}` → `ScenePlanAggregateResponse` —

## Deviations

1. **Router prefix** — plan sketch writes `APIRouter(prefix="/planning/scenes", …)`
   included into the `/planning`-prefixed parent `router.py`; taken literally
   that mounts `GET /api/v1/planning/planning/scenes/…` (FastAPI concatenates
   parent + child prefixes). Spec §5.2 binds the surface to
   `/planning/scenes/{novel_id}/{chapter_id}` and the plan header says the
   spec wins → child prefix is `/scenes` (exact sibling convention of
   `router_timeline.py`'s `prefix="/timeline"`), yielding
   `/api/v1/planning/scenes/…` — proven by the integration tests hitting
   those URLs. Same-alignment detail: the module exports `router` (aliased
   `as scene_router` at the include site) to match the
   `router_timeline`/`router_timeline_analysis` include pattern; the sketch's
   `router_scenes` variable name is cosmetic only.
2. None otherwise. Route names, delegation shape, factory name/signature,
   `uuid.UUID(user_id)` parsing, and 404-handler reuse follow the plan
   sketch verbatim.
