## Generic-variant choice: **union** (plan sketch verbatim)

```python
class ScenePlanAgent(NarrareAgent[ScenePlanDeps, SceneDraftOutput | SceneRefineOutput]):
    def __init__(self, model: Any,
                 output_type: type[SceneDraftOutput] | type[SceneRefineOutput],
                 system_prompt: str | None = None) -> None: ...
```

Verified with `just typecheck-file` (pyright strict) on all three production
files: **0 errors** — no fallback to `OutputT` needed. Pyright accepts
`type[SceneDraftOutput] | type[SceneRefineOutput]` as
`OutputSpec[SceneDraftOutput | SceneRefineOutput]` (metatype special-casing:
each member is assignable to `type[<union>]`), so the base's generic
parameterization does not reject the union. Consequence for T8 call sites:
`run()` returns the union → consumers narrow with
`isinstance(result, SceneDraftOutput)` (pattern demonstrated in the test
file). The constructor union also keeps the API closed: only the two
governed output contracts are accepted.
