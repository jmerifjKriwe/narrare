  `isinstance` dispatch: both shapes share the read attribute names, so only the
  presence ENTRIES are normalized per element (`_presence_pairs`:

  cross-package dependency → no `planning ↔ writing` import cycle (verified both
  import orders). Output is byte-identical for both input types (golden-tested).

  minimal dispatch in `stream_scene_by_scene`: `request.scenes` truthy →
  `scenes = [render_scene_for_prompt(spec, number=idx) for idx, spec in
  enumerate(request.scenes, 1)]` — **no `parse_scenes` call**; `total_scenes` /
  `len(scenes)` naturally equal `len(request.scenes)`. Else the existing
  `parse_scenes(request.outline or context.chapter_outline)` path is UNCHANGED
