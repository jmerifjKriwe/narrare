## Summary

The planning domain's outline surface is beat-free: `BeatSchema` and the
`planned_beats` request/response fields are gone, `to_outline_response` drops
beats, `update_outline` has no beats branch, `OutlineRepository.create` no
longer accepts beats (ORM column default persists `[]` — the column itself dies
in T17), and storyboard sync is computed **over scene plans**
(`ScenePlanRepository.list_by_novel` → per-chapter scene map →
`compute_sync(chapter, outline, suggested, scenes=())`). The KB lifecycle
storyboard consumer scans scene text fields (spec §7) via the new shared
`planning/_helpers.py::iter_scene_texts`. `ensure_outlines` is unchanged
(auto-create still needed for stage assignment). Pydantic default config
ignores unknown request fields, so a legacy client PUTting `planned_beats`
gets 200 with the field ignored (integration-tested).
