## Verdict

The **backend is largely healthy** (200-level APIs beneath nearly every broken UI
surface — proven by direct probes), but the **frontend wiring has decayed badly
across the AI-adjacent surfaces**: 6 features are dead-on-arrival in the UI,
3 more are unreachable, and error handling systematically mis-maps failures to a
hardcoded German "connection lost" string. Non-AI core flows (auth, editor,
autosave, import, scratchpad, stats, export, wizard, demo, i18n switch,
onboarding tour) work well.
