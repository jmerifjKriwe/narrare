### `just verify all` — three runs, one defect found and fixed

**Run 1** stopped at `just test`: `1 failed, 848 passed in 78.91s` —
`app/kernel/tests/test_jobs.py::test_a_restarted_process_completes_an_enqueued_job`,
`InvalidCatalogNameError: database "narrare_v2_test_652f2f8b5301d4ec" does not
exist` at the test's fresh engine connect. The run database demonstrably existed
before and after (848 around it passed).

**Run 2** (`just test` again, for attribution): `2 failed, 847 passed in 76.12s`
— the same jobs test failed at its `sweep` instead:
`asyncio.run() cannot be called from a running event loop`, leaking the `_sweep`
coroutine; the leak GC'd during
`knowledge/tests/test_entities.py::test_another_users_suggestion_cannot_be_reviewed`
and its `RuntimeWarning` (escalated by `filterwarnings = ["error"]`) failed that
unrelated test. Solo, both tests pass (`just test-file` on each: 22/22).

**Attribution: ours.** One root cause, two shapes. `test_testsupport.py`'s
SERVER-override tests `reload(testsupport)` mid-run (404380e9, this branch —
main's file has no reload); `importlib.reload` re-executes the module in its own
dict, rebinding `_NAMES`/`_SWEPT`/`_RUN_DATABASES`/`_RUN_TOKEN` to fresh
empties. The file's own comment knew ("each reload re-mints the run token, so
these two cases run last") — but pytest-randomly shuffles execution across
files, so "last in this file" holds nothing. After a reload, every by-value
importer of `test_database` (app/conftest, the kernel conftest, test_jobs's
`this_run`) sees a fresh module: a sync caller mints a never-created name (run
1's InvalidCatalogName), an async caller dies at sweep's `asyncio.run` and leaks
the coroutine (run 2), and the reset `_RUN_DATABASES` would strand the run's
database at sessionfinish.

**The fix** (red first: `test_a_reload_keeps_this_runs_names` failed against the
old code — the run's `narrare_v2_test_652f2f8b4305c0ef` vs the re-minted
`…19027138` — then passed): the run's caches carry across a reload
(`globals().get("_X") or fresh` in `testsupport.py`), the stale comment in the
test file now states the carry, and the pin holds both the name and the
sessionfinish drop list.

## Final review (fix-before-merge)

The whole-branch review found three defects fixed before merge, each red
first, and filed the minors:

- **N1 — lock-order inversion (fix 6b86581d).** A chapter save took the
  chapter row (the touch's read autoflushes the save's UPDATE) before the
  novel row, while delete/reorder hold the novel row first and rewrite
  chapter rows under it — overlap was Postgres 40P01, a raw 500 in the
  writing loop. `update_chapter` now takes `lock_novel` after its scoped
  load, before the save. Red: the two-session proof against the inverted
  order died on the renumber UPDATE with `DeadlockDetectedError` — the
  review's failure reproduced; green: the gated save and a concurrent
  delete of another chapter both finish, the save still bumps the novel.
- **N2 — the canon shelf E2E hardcoded `127.0.0.1:8000`/`:3100`
  (fix 2cfe0de9).** The one e2e file not importing `API_URL`/`WEB_URL` from
  the stack, defeating this branch's own port isolation. The two constants
  now come from `app/kernel.testing.stack`; `just test-e2e knowledge` green
  (32 passed).
- **N3 — the reorder refusal rendered only inside the rail
  (fix 086c8f2c).** The runhead's move items render at a focus depth that
  hides the rail and with the rail collapsed; a 409 there reverted
  silently. A second notice, the same `orderFailed` state, renders in the
  editor column for exactly those states — `showRail` partitions the two,
  so one is mounted at any time and the alert is announced once. Red: rail
  collapsed, a refused move from the runhead's menu, and no alert existed
  to find; green: the alert names the refusal in the column.
- **N4/N5/N7/N8 filed** as #709 (document delete leaves the cached passage
  search stale), #710 (runhead book title lost truncate, a11y), #711
  ("deleted elsewhere" copy claims a deletion for a never-existed id,
  i18n), #712 (merge revision's downgrade is `pass`, docs-drift); **N9**
  folded into #698 by comment (case-only language edit is a no-op PATCH).
